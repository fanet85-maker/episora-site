Politique de confidentialité

Dernière mise à jour : juillet 2026

Bienvenue sur Episora-WatchMate. Votre vie privée est primordiale pour nous. Voici de manière détaillée comment vos données sont traitées lorsque vous consultez notre site web et lorsque vous utilisez notre application Android.

1. Responsable du traitement

Le responsable du traitement des données collectées via ce site web est l'équipe de développement d'Episora-WatchMate. Pour toute question ou demande concernant votre vie privée, vous pouvez nous contacter via notre page de contact.

2. Données collectées via le site web

Ce site utilise Google Analytics, un service d'analyse web fourni par Google LLC. Google Analytics nous aide à comprendre comment les visiteurs interagissent avec le site (pages les plus consultées, origine géographique générale, durée de visite), uniquement dans le but d'optimiser l'expérience utilisateur.

  • Données collectées : cookies, données d'utilisation génériques, adresses IP anonymisées.
  • Méthode : les données sont collectées sous forme agrégée et anonyme. Google n'associe pas votre adresse IP à d'autres données détenues par Google.
  • Désactivation : vous pouvez désactiver les cookies directement via les paramètres de votre navigateur ou en installant le module complémentaire de désactivation de Google Analytics.

3. Données collectées via l'application Android

Notre philosophie est simple : vos données ne vous appartiennent qu'à vous. L'application Episora-WatchMate est conçue avec une confidentialité maximale :

  • Aucun serveur central : nous ne téléchargeons pas vos habitudes de visionnage ni votre liste de séries vers une base de données centralisée ou un serveur propriétaire.
  • Stockage local : tout votre historique, votre liste à regarder et votre progression sont stockés exclusivement dans la mémoire locale de votre smartphone Android.
  • Sauvegarde personnelle sur Google Drive : si vous activez la fonction de sauvegarde, l'application utilisera les API Google pour enregistrer une copie de vos données directement dans votre espace Google Drive personnel. Nous n'avons aucun accès à ce fichier ni à votre compte Google.

4. Droits des utilisateurs (RGPD)

Conformément au Règlement Général sur la Protection des Données (RGPD), vous avez le droit d'accéder, de rectifier ou de supprimer vos données à tout moment. Comme l'application ne stocke pas de données sur nos serveurs, vous pouvez supprimer définitivement toutes vos données d'utilisation simplement en désinstallant l'application de votre appareil ou en supprimant le dossier de sauvegarde depuis votre Google Drive personnel.

5. Modifications de cette politique de confidentialité

Nous nous réservons le droit d'apporter des modifications à cette politique. Toute modification sera publiée sur cette page avec la date de révision mise à jour.
